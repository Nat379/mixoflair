# Mixoflair — Cocktail Recipes App 🍸

![Demo version](https://img.shields.io/badge/Demo%20version-videos%20removed%20for%20performance-orange)

A Vue.js single-page application showcasing a cocktail recipes catalog.

## 🧠 Project Overview

Mixoflair is a SPA built with Vue 3 that displays a collection of cocktail recipes.
Each recipe is presented as a card with an image, title, category, and detailed
information available in a modal window.

Originally, the project included video recipes.  
For portfolio and performance reasons, videos were removed from the demo version.

---

## ⚠️ Demo Version Notice

> **This is a demo version.**  
> Video files were intentionally removed to:
> - reduce bundle size
> - improve loading performance
> - enable deployment on GitHub Pages

The original version with videos was hosted on a traditional hosting provider.

---

## ✨ Features

- Vue 3 (Options API)
- Component-based architecture
- Data-driven UI (JSON-based recipes)
- Responsive grid layout
- Modal window for recipe details
- Lazy loading for images
- Optimized build for static hosting
- Deployed on GitHub Pages
